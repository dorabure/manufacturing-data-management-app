# スクリーンショット配置予定 Ver1.10

実画面のスクリーンショットを追加する場合は、このフォルダーに配置してください。

推奨する画面は、メイン画面・検索結果、CSV取込、CSV設定、マスタ管理、ErrorLogまたはOperationLogです。画像を追加した後、存在を確認してからルートのREADMEに参照を追加してください。

Ver1.10追加候補：周期モード停止中、監視Running、周期成功後の検索結果、周期OperationLog、CorrectionPending、修正版確認画面、停止待ちの案内。100%／125%／150%の倍率・解像度を記録してください。

Phase 7では実デスクトップ画像を撮影していません。自動Control試験はスクリーンショットの代わりではありません。画像名は撮影後に決め、実在確認前に画像リンクを作らないでください。架空データを使用し、個人パスや実設備情報を公開しないでください。
